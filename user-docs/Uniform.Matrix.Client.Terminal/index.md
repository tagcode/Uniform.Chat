# Uniform.Matrix Terminal Client

A chat client for [Matrix](https://matrix.org), the open chat protocol, that runs in a text terminal: menus, a room list, the message log and members, an input line for messages and irssi-style `/commands`, and a status bar. It supports end-to-end encrypted rooms and files, key backup with a recovery key, and emoji verification of devices. Messages you write are kept on your computer until the server has them, so nothing is lost when the connection drops.

> [!NOTE]
> The client is in early development.
