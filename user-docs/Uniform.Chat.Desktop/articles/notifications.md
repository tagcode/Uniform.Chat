# Notifications

On Linux, the app shows a notification for direct messages, messages that mention you and new invites while its window is in the background. A newer message in the same chat replaces the previous notification. The window title counts rooms with unread messages, such as *Uniform Chat (2)*.

Windows and Android do not show notifications yet.
