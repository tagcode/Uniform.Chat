# Uniform Chat Terminal

A chat client for [Matrix](https://matrix.org), the open chat protocol, that runs in a text terminal: menus, a room list, the message log and members, an input line for messages and irssi-style `/commands`, and a status bar. It supports end-to-end encrypted rooms and files, key backup with a recovery key, and emoji verification of devices. Messages you write are kept on your computer until the server has them, so nothing is lost when the connection drops.

> [!NOTE]
> The client is in early development.

- [Getting started](xref:Uniform.Chat.Terminal.GettingStarted.Article): install, run and log in.
- [Interface](xref:Uniform.Chat.Terminal.Interface.Article): the window, menus and keys.
- [Messages](xref:Uniform.Chat.Terminal.Messages.Article): formatting, replies, edits, reactions and more.
- [Files and images](xref:Uniform.Chat.Terminal.Files.Article): sending, saving and image previews.
- [Encryption and devices](xref:Uniform.Chat.Terminal.Encryption.Article): recovery key, key backup and verification.
- [Room administration](xref:Uniform.Chat.Terminal.Rooms.Article): names, avatars, kicks, bans and power levels.
- [Commands](xref:Uniform.Chat.Terminal.Commands.Article): the `/commands` of the input line.
- [Settings](xref:Uniform.Chat.Terminal.Settings.Article): command-line parameters, the settings file and logs.

There is also a graphical app for Windows, Linux and Android; see its [guide](https://github.com/tagcode/Uniform.Chat/blob/main/user-docs/Uniform.Chat.Desktop/index.md). To run a homeserver of your own, see the [server guide](https://github.com/tagcode/Uniform.Chat/blob/main/user-docs/Uniform.Chat.Server/index.md).
