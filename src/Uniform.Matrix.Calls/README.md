# Uniform.Matrix.Calls

Matrix 1:1 voice and video calls for the Uniform.Matrix client engine: MatrixRTC calls through a LiveKit SFU, as Element X makes them, with Uniform.LiveKit, and legacy calls of `m.call.*` events; WebRTC media with Uniform.Matrix.WebRtc, voice through Uniform.Matrix.Audio, and VP8 video decoded with Uniform.Matrix.Video.
