# Uniform

Package aggregation for server packages. All three apply together: `MIT AND LGPL-3.0-only AND GPL-3.0-only`.

MIT packages:
- [Uniform.Matrix.Server](https://www.nuget.org/packages/Uniform.Matrix.Server): the Matrix homeserver engine on ASP.NET Core and SQLite.
- [Uniform.Matrix.Hosting](https://www.nuget.org/packages/Uniform.Matrix.Hosting): settings layers, the option catalog and session logging for .NET hosts.
ation and the ready-to-run server are at [github.com/tagcode/Uniform.Matrix](https://github.com/tagcode/Uniform.Matrix).
