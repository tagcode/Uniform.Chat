# Uniform.Matrix.Gui.Terminal

Terminal.Gui components without Matrix types, for every terminal application:

- [`SettingsWindow`](xref:Uniform.Matrix.Gui.Terminal.SettingsWindow) lists a [`SettingsEditor`](xref:Uniform.Matrix.Hosting.SettingsEditor)'s options with value, source and description, and edits, resets, applies, saves, loads and exports them.
- [`LogWindow`](xref:Uniform.Matrix.Gui.Terminal.LogWindow) lists session logs, filters entries by level and text, colors them by level, shows whole entries and follows the current file.
- [`Dialogs`](xref:Uniform.Matrix.Gui.Terminal.Dialogs) has the general prompts: ask, confirm, choose, pick one of a list, pick a file, show text or a value to copy.
- [`TextWrapper`](xref:Uniform.Matrix.Gui.Terminal.TextWrapper) wraps text by terminal columns, so emoji and CJK take two.
