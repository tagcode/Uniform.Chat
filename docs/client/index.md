# Uniform.Matrix Client

Chat clients for [Matrix](https://matrix.org), the open chat protocol: one for the text terminal, and a graphical app for Windows, Linux and Android. Both use the same engine, so messages, end-to-end encryption and the outbox, which keeps messages until the server has them, work the same way.

The terminal client has menus, a room list, the message log and members, an input line for messages and irssi-style `/commands`, and a status bar.

The desktop and Android app shows rooms, formatted messages, replies and reactions, files, invites, and encryption with recovery and emoji verification in a graphical window.

> [!NOTE]
> The clients are in early development. The terminal client supports end-to-end encrypted rooms and files, key backup with a recovery key, and emoji verification of devices.

- [Getting started](articles/getting-started.md): run the terminal client and log in.
- [Interface](articles/interface.md): the terminal client's menus, keys and commands.
- [Desktop and Android app](articles/desktop.md): install, sign in, rooms and files.

To run a homeserver of your own, see the [server guide](https://github.com/tagcode/Uniform.Matrix/blob/main/docs/server/index.md).
